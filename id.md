# 📜 Kebijakan Privasi

**Terakhir Diperbarui:** 16 Juli 2026

## Komitmen Privasi

Aplikasi ini menghormati privasi Anda dan berkomitmen untuk melindungi data pribadi Anda. Aplikasi ini menerapkan prinsip pengumpulan data seminimal mungkin, yaitu hanya mengumpulkan data yang diperlukan untuk menjalankan fungsi utamanya. Pengembang tidak mengumpulkan data pribadi secara langsung.

## Data yang Dikumpulkan

Aplikasi ini **tidak** mengumpulkan atau menyimpan informasi identitas pribadi seperti nama, nama belakang, alamat email, nomor telepon, atau lokasi di servernya sendiri.

Namun, aplikasi ini menggunakan **Google AdMob** untuk menampilkan iklan. Sebagai bagian dari layanan ini, data berikut dapat dikumpulkan dan diproses secara otomatis oleh Google (pihak ketiga):

* Pengenal perangkat atau pengenal lainnya (Advertising ID)
* Data interaksi aplikasi (seperti tayangan dan klik iklan)
* Data diagnostik dan kinerja

Data ini diproses oleh Google untuk tujuan penayangan iklan, personalisasi iklan, dan pengukuran kinerja.

Pengguna dapat:

* Mengatur ulang Advertising ID melalui pengaturan perangkat.
* Menonaktifkan iklan yang dipersonalisasi melalui pengaturan perangkat.

Untuk informasi lebih lanjut mengenai kebijakan pemrosesan data Google, silakan kunjungi:

https://policies.google.com/privacy

## Penyimpanan Lokal (Local Storage)

Jumlah zikir, statistik, dan pengaturan aplikasi disimpan **hanya di perangkat pengguna** menggunakan AsyncStorage. Data ini tidak dapat diakses oleh pengembang, tidak dikirim ke server eksternal mana pun, dan akan dihapus saat aplikasi dihapus dari perangkat.

## Layanan Pihak Ketiga

Aplikasi ini menggunakan **Google AdMob** untuk menampilkan iklan. AdMob dapat mengumpulkan dan memproses informasi tertentu, seperti pengenal perangkat dan Advertising ID, untuk tujuan penayangan iklan.

Seluruh transmisi data dilakukan melalui koneksi aman menggunakan **HTTPS/TLS**.

## Izin Notifikasi

Aplikasi ini dapat meminta izin untuk mengirim notifikasi sebagai pengingat zikir dan hari-hari besar Islam. Pemberian izin ini sepenuhnya bersifat opsional dan dapat dinonaktifkan kapan saja melalui pengaturan perangkat.

## Privasi Anak

Aplikasi ini **tidak ditujukan khusus untuk anak-anak di bawah usia 13 tahun**. Tidak ada data pribadi anak yang dikumpulkan secara sengaja.

## Keamanan Data

Data yang dikirimkan melalui aplikasi dan layanan pihak ketiga dilindungi menggunakan koneksi aman **HTTPS/TLS**.
