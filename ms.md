# 📜 Dasar Privasi

**Kemas Kini Terakhir:** 16 Julai 2026

## Komitmen Privasi

Aplikasi ini menghormati privasi anda dan komited untuk melindungi data peribadi anda. Aplikasi ini beroperasi berdasarkan prinsip pengumpulan data minimum, iaitu hanya mengumpulkan data yang diperlukan untuk menjalankan fungsi terasnya. Pembangun tidak mengumpulkan sebarang data peribadi secara langsung.

## Data yang Dikumpulkan

Aplikasi ini **tidak** mengumpulkan atau menyimpan maklumat pengenalan peribadi seperti nama, nama keluarga, alamat e-mel, nombor telefon atau lokasi pada pelayannya sendiri.

Walau bagaimanapun, aplikasi ini menggunakan **Google AdMob** untuk memaparkan iklan. Sebagai sebahagian daripada perkhidmatan ini, data berikut mungkin dikumpulkan dan diproses secara automatik oleh Google (pihak ketiga):

* Pengecam peranti atau pengecam lain (Advertising ID)
* Data interaksi aplikasi (seperti paparan dan klik iklan)
* Data diagnostik dan prestasi

Data ini diproses oleh Google untuk tujuan penyampaian iklan, pemperibadian iklan dan pengukuran prestasi.

Pengguna boleh:

* Menetapkan semula Advertising ID melalui tetapan peranti.
* Melumpuhkan iklan yang diperibadikan melalui tetapan peranti.

Untuk maklumat lanjut mengenai dasar pemprosesan data Google, sila lawati:

https://policies.google.com/privacy

## Storan Tempatan (Local Storage)

Bilangan zikir, statistik dan tetapan aplikasi disimpan **hanya pada peranti pengguna** menggunakan AsyncStorage. Data ini tidak boleh diakses oleh pembangun, tidak dihantar ke mana-mana pelayan luaran, dan akan dipadamkan apabila aplikasi dinyahpasang.

## Perkhidmatan Pihak Ketiga

Aplikasi ini menggunakan **Google AdMob** untuk memaparkan iklan. AdMob mungkin mengumpulkan dan memproses maklumat tertentu seperti pengecam peranti dan Advertising ID bagi tujuan penyampaian iklan.

Semua penghantaran data dilakukan melalui sambungan yang selamat menggunakan **HTTPS/TLS**.

## Kebenaran Pemberitahuan

Aplikasi ini mungkin meminta kebenaran untuk menghantar pemberitahuan bagi peringatan zikir dan hari-hari kebesaran Islam. Kebenaran ini adalah sepenuhnya pilihan dan boleh dinyahaktifkan pada bila-bila masa melalui tetapan peranti.

## Privasi Kanak-Kanak

Aplikasi ini **tidak direka khas untuk kanak-kanak di bawah umur 13 tahun**. Tiada data peribadi kanak-kanak dikumpulkan dengan sengaja.

## Keselamatan Data

Data yang dihantar melalui aplikasi dan perkhidmatan pihak ketiga dilindungi menggunakan sambungan selamat **HTTPS/TLS**.
